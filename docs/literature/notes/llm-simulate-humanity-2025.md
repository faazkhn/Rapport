# Can LLMs Simulate Humanity?: From ChatGPT to DeepSeek: Can LLMs Simulate Humanity?

- **Citation:** Wang Q, Tang Z, He B. arXiv preprint (adapted from ICLR 2025 blogpost), 2025. arXiv:2502.18210
- **Link:** https://arxiv.org/abs/2502.18210 · **Open access:** yes (full text read, 12 pp)
- **Code:** none found · **Code licence:** none
- **Paper licence:** CC BY 4.0
- **Informs:** none (background for identity/formulation and affect)

## Mechanism
Position paper, no system. Argues LLM social simulation is limited because training data lacks inner psychological states and personal life histories, LLMs lack intrinsic motivation, and one LLM prompted as many personas shares one core knowledge, so diversity is shallow. Still judges simulation promising on cost, scale and emergent behaviour.

## Evidence
No quantitative results.

## Limitations
- Opinion/survey; no experiments.
- Not specific to clinical or patient simulation.

## For Rapport
**Verdict:** idea-only. It supports the Digital Twin design choice of explicit per-case identity, memory and state held in code rather than relying on the LLM to improvise an inner life.
