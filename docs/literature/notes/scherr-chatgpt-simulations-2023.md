## Mechanism
Authors refined starting prompts for ChatGPT 3.5 to run text clinical simulations (ACLS, ICU sepsis, pneumonia).

## Evidence
Prompt 1 built via 3 test sims, used in 2; prompt 2 via 10 test sims, used in 1. No quantitative outcomes.

## Limitations
- Three simulations, no learner study.
- Accuracy and replicability concerns noted by authors.
