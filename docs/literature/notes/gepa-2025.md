# GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

- **Citation:** Agrawal LA, Tan S, Soylu D, et al., ICLR 2026 (oral). arXiv:2507.19457 (v2 Feb 2026).
- **Link:** https://arxiv.org/abs/2507.19457 · **Open access:** yes (full text read)
- **Code:** https://github.com/gepa-ai/gepa · **Code licence:** MIT (LICENSE file checked)
- **Paper licence:** arXiv non-exclusive
- **Informs:** learning

## Mechanism
Optimises the prompts of a multi-module LLM system with weights frozen. Loop: pick a candidate from the Pareto frontier (for each training instance keep the candidates that score best on it; sample among them weighted by how many instances each leads), run it on a minibatch with traces, call a feedback function that returns a score plus text (failed rubric, error message), pick a module round-robin, and have a reflection LLM rewrite that module's prompt from (prompt, trajectory, score, feedback). Keep the child only if it beats the parent on the minibatch, then score it on the validation set D_pareto. Optional "System Aware Merge" crosses two lineages. Returns the best aggregate candidate on D_pareto. Offline, many LLM calls; the optimised prompt itself adds no runtime calls.

## Evidence
Six tasks (HotpotQA, IFBench, HoVer, PUPA, AIME-2025, LiveBench-Math). Qwen3 8B: aggregate baseline 45.23, GRPO (LoRA, 24,000 rollouts) 48.91, MIPROv2 47.84, GEPA 54.85 (+9.62) using 1,839 to 7,051 rollouts; GEPA beats GRPO on 5 of 6 tasks (not AIME-2025: 32.0 vs 38.0), by up to 19%, with up to 35x fewer rollouts. IFBench: 38.61 after 678 rollouts vs GRPO 35.88. GPT-4.1 Mini: baseline 53.03, MIPROv2 58.67, TextGrad 59.14, GEPA 65.22, GEPA+Merge 66.36. Prompts optimised on Qwen3 8B transferred to GPT-4.1 Mini for +9.00 aggregate. Most rollouts go to validation scoring, not learning. Note: the README figures (e.g. AIME 46.6 to 56.6) are not the paper's tables.

## Limitations
- Needs a metric and a feedback function that return diagnostic text; a weak metric will be gamed.
- Gains vary: AIME-2025 favoured GRPO; Merge hurt IFBench (28.23).
- Benchmarks are QA, maths and instruction following, with single gold answers; no dialogue or persona fidelity tasks.
- Optimised prompts grow long (prompt-length cost reported in appendix).

## For Rapport
**Verdict:** adopt. MIT licence, works on a small local model's prompt with a few hundred rollouts. Use it nightly on the Digital Twin's single-call patient prompt, with the feedback function built from code checks (JSON schema, fact and lock violations, clamped-state sanity) plus an order-swapped judge, and a hard gate: only prompt text outside clinical facts and scoring may change, and a candidate is promoted only if it wins on a held-out validation set. The Pareto frontier suits our need for per-case diversity.
